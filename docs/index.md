# Plone Conference Organizers Handbook

This handbook is a public, community-maintained manual for organizing Plone conferences.
It collects what previous organizers learned, so that the next team doesn't start from nothing.
Both spellings, organizers and organisers, point here.
Every part is written; pages carry a maturity of stub or draft, and thin content is marked where it occurs.
