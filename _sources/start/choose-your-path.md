# Choose your path

Nobody reads a handbook front to back.
Pick the path that matches your role or your phase, read the pages in the order given, then follow the links inside them.
Each item below is a page id from the handbook's master chapter list.
The id is shown in backticks, followed by the page title.

If you have 90 days or fewer before the event, start with the phase list for the final build and the incident playbooks, then return to the role lists.

## By role

### Bidder

You are deciding whether to propose a conference and where.

1. `stakeholder-map` (Stakeholder map)
2. `bid-and-selection` (Bid and selection)
3. `defining-success` (Defining success)
4. `city-selection` (City selection)
5. `legal-entity-and-financial-agent` (Legal entity and financial agent)
6. `finance` (Finance)

### Chair or lead organizer
